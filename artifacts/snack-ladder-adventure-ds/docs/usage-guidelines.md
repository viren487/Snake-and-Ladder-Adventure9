# Extracted usage guidelines

These describe repeated patterns found in the current source. No separate written brand rules were provided.

## Visual identity
- Use a midnight navy shell with warm gold for primary actions and focus; jade marks positive states.
- Keep controls layered in deep blue, with quiet warm borders and restrained glow/shadow.
- Keep the board the high-saturation focal point: green, cream/yellow and cyan tiles inside a decorative bamboo/gold frame.
- Use the existing panda, snake and ladder art. In-game power icons should read as simple symbols, not photo-like card art.

## Type and hierarchy
- Fredoka is the display face for playful titles and board numerals; Nunito is body/UI; DM Mono is compact labels and metadata.
- Keep labels short. Reserve uppercase/letter-spaced mono for metadata rather than paragraphs.

## Components and interaction
- Primary actions use gold with dark text; secondary controls use navy/blue surfaces. Reserve red for danger and selected aim states.
- Give controls visible gold focus rings and distinct disabled/selected states.
- Keep status chips compact; use pills for mode/connectivity rather than large callouts.
- Preserve touch-friendly hit areas on mobile and keep metadata from competing with the board.
- Round ordinary controls and panels; allow the board frame to use heavier decorative treatments.

## Motion
- Use brief easing for hover/focus feedback. Character movement should feel deliberate; reserve shake/flash for impacts such as bomb blasts.
